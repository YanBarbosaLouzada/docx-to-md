Objetivos

Estratégias e atividades

Na aula de hoje vamos aprender a como criar e editar corretamente __estradas\. __Por meio do pacote __Easy Roads 3D__, podemos podemos usar o editor diretamente para desenhar as estradas que se adaptam ao terreno existente\.

__START__

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767708601952593400.png)

Para testar o veículo em maior velocidade, precisamos de uma estrada\. Para criar estradas utilizaremos o pacote __Easy Roads 3D__, que facilita essa implementação:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767708601955594500.png)

Com o Easy Roads 3D, podemos criar estradas com poucos cliques que irão estar niveladas com o terreno, ficando assim mais realistas\. No painel Hierarchy, vamos adicionar um novo objeto do tipo EasyRoads3D:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767708601962178600.png)

Selecione o objeto __Road Network__ e clique em __Add Road Object__ para criar uma nova estrada na rede de estradas:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767708601968329700.png)

Agora, segure a tecla SHIFT e clique com o mouse nos pontos do terreno, traçando assim o caminho da estrada:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767708601971515900.png)

Após concluir a estrada, utilizamos a opção __Update Terrain__ para nivelar o terreno com as estradas:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767708601975226900.png)

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767708601975226900.png)

Expanda as estradas existentes no mapa e modifique o terreno para adicionar elementos como árvores, montanhas e outros objetos que tragam vida ao cenário\. Pense em como cada novo detalhe pode contribuir para a imersão no jogo, mantendo sempre a criatividade e a coerência em mente ao inserir esses elementos\. Lembre\-se de que um cenário bem construído é fundamental para criar uma experiência visualmente rica e envolvente para o jogador\.
