__PLANO DE AULA  
Aula 02 | Tempo estimado:__ 1 hora e 30 minutos | __Faixa\-Etária:__ Basic 2  
__Tipo da atividade:__ Offline  
__Ferramenta\(s\):__ Papel, lápis, borracha e projetor

### <a id="_5ae65kj8z9am"></a>__Conteúdos__

- Arquitetura de Computadores
- Sistemas Operacionais: Funções e Importância
- Introdução à Linguagem de Programação

### <a id="_3m9trz382shf"></a>__Objetivos__

- Compreender a organização básica de um computador e seus componentes;
- Identificar o papel do Sistema Operacional como gerenciador de hardware e software;
- Entender o que são linguagens de programação e como elas interagem com o hardware\.

### <a id="_arfl8pik30zz"></a>__Estratégias e Atividades__

#### <a id="_7oxob9sevybf"></a>__1\. Arquitetura de Computadores__

__Definição:__ Organização lógica que define como os componentes de hardware interagem\.

__Para o professor:__  
	Vídeo explicando a ULA: [Vídeo 25 \- ULA](https://www.youtube.com/watch?v=4wkT-3DD4PY)

- __Componentes principais:__
	- __CPU:__ Controle, Unidade Lógica e Aritmética \(ALU\) e registradores\.
		- Vídeo para as crianças: [Aula 02](https://drive.google.com/drive/folders/1_4Fb2hpAjW9DkvIO4cCDER5BKwO4rqSS)
	- __Memória Principal:__ RAM e ROM\.
	- __Dispositivos de Entrada e Saída:__ Teclado, mouse, monitor\.
	- __Barramentos:__ Interconexões que transportam dados, controle e endereços\.
- __Atividade prática:  
__Distribuir uma folha com o desenho de um computador básico \(arquitetura\) e pedir aos alunos que identifiquem e descrevam os principais componentes\.

#### <a id="_mpqb9n7mf4fz"></a>__2\. Sistemas Operacionais: Funções e Importância__

- __Definição:__ Software que gerencia recursos de hardware e fornece serviços para o usuário\.
- __Funções principais:__
	- Gerenciamento de Processos;
	- Gerenciamento de Memória;
	- Gerenciamento de Dispositivos;
	- Interface com o Usuário\.
- __Atividade prática:  
__Exibir o vídeo: [Aula 02](https://drive.google.com/drive/folders/1_4Fb2hpAjW9DkvIO4cCDER5BKwO4rqSS)[  
](https://www.youtube.com/watch?v=26QPDBe-NB8)Após o vídeo, discutir como o Sistema Operacional atua como ponte entre o hardware e os aplicativos que usamos diariamente\.

#### <a id="_hgqoycyx5ci4"></a>__3\. Introdução à Linguagem de Programação__

- __Definição:__ Linguagem usada para criar software, permitindo que programadores escrevam instruções que o computador pode executar\.
- __Exemplos:__ Python, Java, C\+\+\.
- __Níveis de Linguagens:__
	- __Linguagem de baixo nível:__ Mais próxima do hardware, como Assembly\.
	- __Linguagem de alto nível:__ Mais próxima do ser humano, como Python\.
- __Atividade prática:  
__Pedir aos alunos para escreverem instruções simples em pseudocódigo \(exemplo: "Se temperatura > 30, ligar ventilador"\)\.
