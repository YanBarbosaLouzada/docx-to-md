Aula 22 | Tempo estimado: 1 hora e 30 minutos | Faixa\-Etária: Basic 2 

Tipo da atividade: No computador

Ferramenta\(s\): Kodu

Conteúdos 

- Game Jam\.

Objetivos

- Criar um projeto e personalizá\-lo com a própria identidade e tentar adicionar melhorias por conta própria\.

Estratégias e atividades

- Ajudar os alunos no desenvolvimento da Game Jam\. 

Recursos

- Computador, internet e Godot\.

Observação

- O que é uma Game Jam:
	- Uma Game Jam é um evento no qual desenvolvedores de jogos se reúnem por um curto período, para criar ou modificar jogos rapidamente com base em um tema específico\. O objetivo é estimular a criatividade, colaboração e desenvolvimento rápido de jogos\.
