Estratégias e atividades

- Instalação do VS Code:
	- Baixar o Visual Studio Code \(VSCode\):
		- Acesse \[[https://code\.visualstudio\.com/download](https://code.visualstudio.com/download)\];
		- Clique em "Download" para obter o instalador;
		- Execute o instalador após o download e siga as instruções\.
- Instalação de Extensões \(opcional\):
	- No VS Code, vá para a barra lateral esquerda e clique no ícone de extensões \(quatro quadrados\)\.
	- Pesquise e instale extensões úteis, como "Python" para suporte ao desenvolvimento Python\.
- Sintaxe, Tipos de Variáveis, Entrada e Saída de Dados:

*Código de Exemplo:*

\# Exemplo de sintaxe, tipos de variáveis e entrada/saída de dados

\# Declaração de variável

numero\_inteiro  = 3		\# Variável do tipo int \(inteira\)

numero\_decimal = 5\.2	\# Variável do tipo float \(decimal\)

nome = “Pedro”		\# Variável do tipo String \(texto\)

ligado = True			\# Variável do tipo boleana \(verdadeiro ou falso\)

\# Entrada de dados

nome = input\("Digite seu nome: "\)  

\# Saída de dados

print\("Olá, " \+ nome \+ "\!"\)

\# Operações com variáveis

idade = int\(input\("Digite sua idade: "\)\)  \# Convertendo entrada para inteiro

ano\_nascimento = 2023 \- idade

\# Saída de dados formatada

print\(f"Você nasceu aproximadamente em \{ano\_nascimento\}"\)

- Explicação:
	- __input\(\):__ Solicita uma entrada do usuário e retorna uma string;
	- __print\(\):__ Exibe uma mensagem na tela;
	- __int\(\):__ Converte uma string para um número inteiro\.

\# Indentação

def exemplo\_indentacao\(\):

    print\("Estou dentro da função\."\)

print\("Estou fora da função\."\)

- Explicação:
	- A indentação organiza o código, agrupa comandos com uma mesma função e define a ordem da execução dos comandos\.
