# __PLANO DE AULA__

Aula 23 | Tempo estimado: 1 hora e 30 minutos | Faixa\-Etária: Game Starter 

Tipo da atividade: No computador

Ferramenta\(s\): Roblox

Conteúdos 

- Game Jam\.

Objetivos

- Aplicar os conhecimentos adquiridos durante as aulas;
- Visual Mapa\.

Estratégias e atividades

- Hoje, vocês vão usar tudo o que aprenderam sobre Roblox Studio para criar seu próprio projeto\. Esta é uma ótima oportunidade para mostrar sua criatividade e aplicar as habilidades que adquiriram\.

Antes de começar a criar, é importante planejar seu projeto\. Responda as seguintes perguntas para ajudar no seu planejamento:

1. __Qual é o tema do seu projeto?__
	- Será um jogo de aventura, simulação, corrida, quebra\-cabeça, etc\.?
2. __Quais são os principais elementos do seu jogo?__
	- Personagens, terrenos, obstáculos, itens colecionáveis, etc\.
3. __Qual é o objetivo do jogador?__
	- O que o jogador deve fazer para vencer ou progredir no jogo?
4. __Quais mecânicas você vai usar?__
	- Movimento dos personagens, interação com objetos, sistema de pontos, etc\.
5. __Como será o visual do seu jogo?__
	- Estilo artístico, paleta de cores, design dos personagens e ambientes\.

__Dica:__ Faça um esboço ou uma lista dos elementos do seu jogo para ajudar a visualizar\.

Agora que você tem um plano, é hora de colocar a mão na massa\!

### <a id="_heading=h.1493ewx8slr9"></a>__Passo 1: Configurar o Terreno e o Ambiente__

- Use as ferramentas de construção para criar o cenário do seu jogo\.
- Adicione terrenos, construções, água, árvores, e outros elementos do ambiente\.

### <a id="_heading=h.fkj671tdyh0y"></a>__Passo 2: Adicionar Personagens e Objetos__

- Insira modelos de personagens e objetos no seu jogo\.
- Configure as propriedades dos objetos \(tamanho, cor, textura, etc\.\)\.

### <a id="_heading=h.6p0qfy4i5iqr"></a>__Passo 3: Programar a Interatividade__

- Crie scripts em Lua para adicionar funcionalidade ao seu jogo\.
- Exemplo de scripts que você pode criar:
	- Movimento do personagem principal\.
	- Regras de colisão e física\.
	- Eventos ao clicar em objetos ou ao passar por determinados pontos do cenário\.

### <a id="_heading=h.1g7icfol1rks"></a>__Passo 4: Testar e Ajustar__

- Teste seu jogo frequentemente para ver como ele está ficando\.
- Ajuste e refine os elementos do jogo conforme necessário\.
- Verifique se há bugs ou problemas e corrija\-os\.

Recursos

- Computador, internet e Roblox Studio\.

Observação

- Link para download do Roblox Studio: [https://create\.roblox\.com/](https://create.roblox.com/) 

Tarefas
