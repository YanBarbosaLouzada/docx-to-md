# __PLANO DE AULA__

Aula 7 | Tempo estimado: 1 hora e 30 minutos | Faixa\-Etária: Basic 3

Tipo da atividade: Online

Ferramenta\(s\): Godot instalado no computador

Conteúdos

-  Aula extra

Objetivos

- Deixar aula para que os alunos mexam em seus projetos e façam alterações e adições a ele\.  


Estratégias e atividades

Nesta aula extra, vamos modificar o projeto base do nosso RPG, adicionando novas funcionalidades e personalizações\. Vocês terão a oportunidade de implementar novas áreas, novos inimigos, e outras mecânicas para enriquecer seu jogo\. Vamos começar com uma breve revisão dos conceitos básicos e, em seguida, mergulhar nas novas funcionalidades\.

### <a id="_t6oyitarvkni"></a>__Revisão do Projeto Base__

__1\. Movimentação:__

- O jogador pode se mover usando as teclas direcionais ou WASD\.
- A movimentação está ligada à animação do personagem para que ele ande na direção correta\.

__2\. Animação:__

- As animações de caminhada e parada do personagem são ativadas conforme a movimentação\.
- A troca de animação é feita com base na direção do movimento\.

__3\. Cenário:__

- O cenário é composto por diferentes tiles, formando o ambiente do jogo\.
- Existem colisões configuradas para limitar a movimentação do personagem\.

__4\. Inimigos:__

- Os inimigos patrulham uma área ou seguem um padrão de movimento\.
- Quando o jogador entra em contato com o inimigo, uma interação ocorre \(como uma batalha ou perda de vida\)\.

### <a id="_xkn9r0df5uth"></a>__Personalização do Projeto__

__Escolha uma ou mais das seguintes modificações para implementar:__

__1\. Novas Áreas e Cenários:__

- Crie novos níveis ou áreas no jogo\.
- Use o sistema de Tilemap para construir novos cenários\.
- Configure transições entre áreas usando portas ou caminhos\.

__2\. Novos Tipos de Inimigos:__

- Adicione novos inimigos com comportamentos diferentes\.
- Crie novos scripts para definir os padrões de movimento e ataque dos novos inimigos\.

__3\. Missões e Tarefas:__

- Implemente missões que o jogador deve completar\.
- Use um sistema de objetivos para rastrear o progresso das missões\.

__4\. Efeitos Visuais e Sonoros:__

- Adicione novos efeitos visuais, como partículas ou luzes\.
- Incorpore novos sons para ações como ataques, coleta de itens, ou diálogos\.
