# __PLANO DE AULA__

Aula 15 | Tempo estimado: 1 hora e 30 minutos | Faixa\-Etária: Basic 3

Tipo da atividade: Online

Ferramenta\(s\): Godot instalado no computador

Conteúdos

-  Aula extra

Objetivos

- Deixar aula para que os alunos mexam em seus projetos e façam alterações e adições a ele\.  


Estratégias e atividades

Nesta aula extra, vamos modificar o projeto base do nosso clone do Flappy Bird, adicionando novas funcionalidades e personalizações\. Vocês terão a oportunidade de implementar novos obstáculos, power\-ups, diferentes modos de jogo, e outras mecânicas para enriquecer seu jogo\. Vamos começar com uma breve revisão dos conceitos básicos e, em seguida, mergulhar nas novas funcionalidades\.

### <a id="_hwyktkmysypt"></a>__Revisão do Projeto Base__

### <a id="_t6oyitarvkni"></a>__1\. Movimentação do Personagem:__

### <a id="_t6oyitarvkni"></a>O jogador controla o personagem \(pássaro\) com cliques ou toques para fazê\-lo voar para cima\.

### <a id="_t6oyitarvkni"></a>A gravidade puxa o pássaro para baixo constantemente\.

### <a id="_t6oyitarvkni"></a>__2\. Geração de Obstáculos:__

### <a id="_t6oyitarvkni"></a>Os obstáculos \(canos\) aparecem de forma contínua, movendo\-se da direita para a esquerda\.

### <a id="_t6oyitarvkni"></a>A altura dos canos varia para criar desafios\.

### <a id="_t6oyitarvkni"></a>__3\. Detecção de Colisões:__

### <a id="_t6oyitarvkni"></a>O jogo detecta colisões entre o pássaro e os obstáculos ou o chão\.

### <a id="_6fy8zycklwuq"></a>Quando uma colisão é detectada, o jogo termina\.

### <a id="_c0caxr3crppm"></a>__Personalização do Projeto__

### <a id="_t6oyitarvkni"></a>__Escolha uma ou mais das seguintes modificações para implementar:__

### <a id="_t6oyitarvkni"></a>__1\. Novos Cenários:__

### <a id="_t6oyitarvkni"></a>Crie novos cenários com diferentes temas \(ex: deserto, cidade, espaço\)\.

### <a id="_t6oyitarvkni"></a>Use o sistema de Tilemap para construir os cenários\.

### <a id="_t6oyitarvkni"></a>__2\. Novos Personagens:__

### <a id="_t6oyitarvkni"></a>Adicione novos personagens jogáveis com habilidades únicas\.

### <a id="_t6oyitarvkni"></a>Crie um menu de seleção de personagens\.

### <a id="_t6oyitarvkni"></a>__3\. Sistema de Pontuação:__

### <a id="_t6oyitarvkni"></a>Implemente um sistema de pontuação com bônus para coletar itens especiais\.

### <a id="_t6oyitarvkni"></a>Adicione uma tabela de líderes para registrar as melhores pontuações\.

### <a id="_t6oyitarvkni"></a>__4\. Efeitos Visuais e Sonoros:__

### <a id="_t6oyitarvkni"></a>Adicione novos efeitos visuais, como explosões ou brilhos ao coletar power\-ups\.

### <a id="_ec1ve2vp4rr"></a>Incorpore novos sons para ações como voar, colidir com obstáculos, ou coletar power\-ups\.
