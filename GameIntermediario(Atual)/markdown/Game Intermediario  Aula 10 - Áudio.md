Estratégias e atividades

-  Intro\.
	- Primeiramente precisamos fazer o download dos assets do som que estão disponíveis no Google Docs\.
- __Audio Source:__
- Criar um GameObject vazio\.
	- Na Unity, clique com o botão direito no Hierarquia \(Hierarchy\);
	- Escolha "Create Empty" para criar um novo GameObject vazio\.
- Renomear o GameObject para "Source Manager"\.
	- Selecione o GameObject vazio criado;
	- No painel Inspector, renomeie o GameObject para "Source Manager"\.
- Adicionar um componente AudioSource\.
	- Com o "Source Manager" selecionado, vá até o Inspector;
	- Clique em "Add Component" \(Adicionar Componente\);
	- Digite "Audio Source" na barra de pesquisa e selecione para adicionar o componente "AudioSource";
	- Arraste a música de fundo do seu jogo para a opção "AudioClip" no componente AudioSource\.
- Criar um Script chamado "SoundManager"\.
	- Na área de projetos da Unity, clique com o botão direito;
	- Escolha "Create" \(Criar\) e depois "C\# Script";
	- Renomeie o script para "SoundManager";
	- Arraste e solte o script "SoundManager" no GameObject "Source Manager" na Hierarchy\.
- Compartilhe o script\.
	- Abra o script "SoundManager" dando um clique duplo sobre ele na Unity\.
	- Copie o código do script\.
