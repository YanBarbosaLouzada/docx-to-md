Estratégias e atividades

- Cena 
	- Primeiramente duplique a cena de Game Over e mude o nome para Pause Screen\.
	- Mude o texto Game over para Pause 
	- Duplique o Restart 3 vezes e renomeie para Music, Volume e Resume\.
	- Agora no Select Arrow adicione estas novas opções\.

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767727588942773600.png)

- Scripts
	- Vamos criar dois scripts VolumeText, LoadingManager\.
	- Vamos alterar coisas no SoundManager, UiManager e no PlayerRespawn \.
- Configuração de Componentes
	- O script volume você pode arrastar para opção volume e para o music\.
	- ![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767727588944466100.png)
	- ![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767727588946461000.png)
	- No UI canvas não esqueça de arrastar a cena do Pause Screen para o script UI Manager
	- SoundManager você pode colocar dentro do ui canvas, ele pode estar dentro da câmera e se não estiver basta criar um SoundManager colocar o audio source\(Componente\) e o script do SoundManager e dentro dele você cria o Music Source com AudioSource\(componente também\)\.
	- Dentro das opções novas no menu de Pause você deve colocar as funções referente ao botão\.
