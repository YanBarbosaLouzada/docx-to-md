Estratégias e atividades

- Para criar nosso boss precisamos primeiro criar uma prefab do Spikehead e dentro do nosso Spikehead vamos colocar os componentes: 

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767727589005163100.png)

- No Box Collider 2D vamos ativar o istrigger 
- Vamos colocar o componente Health\(Script\), dentro dele coloque a dificuldade que deseja no seu boss\.
- Por fim vamos criar o script do Spikehead;
- Posicione o boss dentro do seu jogo e coloque as dependências do script spikehead
- ![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767727589006938100.png)
- Crie as animações idle e die do nosso boss, na animação die coloque a função desactive\.\.
- ![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767727589008939600.png) 
- Depois de terminamos o boss, repare nos códigos de movimento do player, player attack os códigos tem comentários para que consiga jogar no controle
