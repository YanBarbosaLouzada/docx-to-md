Estratégias e atividades

- Na aula de hoje os alunos irão aprender um novo estilo de jogo, o estilo de Quiz\. Um Quiz é um jogo de perguntas e respostas onde o jogador deve escolher a opção correta para passar para a próxima pergunta\. Sendo assim, iremos fazer um clone do jogo “Gênio Quiz”\.
- Para fazer isso precisamos criar ou pegar uma bolinha pronta no scratch e criar também 4 quadrados de cor diferente\.  
  
![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545614523300.png)
- O nosso principal ator será a bola, mas antes precisamos fazer um questionário usando o cenário
- Lembre\-se de utilizar o texto para fazer as perguntas dessa forma:  
![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545616523600.png)
- Para fazer mais perguntas você deve apenas duplicar a tela e trocar os textos\.
- Agora devemos posicionar os quadrados dessa forma na tela:  
![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545655203600.png)
- Após isso, devemos fazer a programação da bolinha:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545657210600.png) \. 

- Você pode fazer isso para cada um dos cenários \( Perguntas \) lembrando sempre de trocar o numero do cenário no primeiro SE dá programação e a programação da resposta certa\.
