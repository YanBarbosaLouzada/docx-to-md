# __PLANO DE AULA__

Aula 18 | Tempo estimado: 1 hora e 30 minutos | Faixa\-Etária: Basic 1

Tipo da atividade: Online

Ferramenta\(s\): Computador com Aseprite instalado

	     

Conteúdos

- Desenhar pixel art

Objetivos

- Entender o que é um pixel;
- Resolução;
- Pixel art\.

Estratégias e atividades

- O que é um pixel
	- Explicar que o pixel é o menor elemento da tela, que juntando esse pixels forma uma imagem\.
- Resolução da imagem
	- Explique aos alunos que a resolução nada mais é do que a quantidade de pixels que uma tela ou desenho tem\. Fale sobre a televisão, sobre a tela do computador e, se achar interessante, deixei uma tabela sobre resolução abaixo\. Claro que você, como professor, pode dar os exemplos que achar melhor\.

- Vamos para o Aseprite\. Na aula de hoje os alunos vão montar algumas pixel art, para mostrá\-los o que é uma pixel art, mostre algum jogo antigo, conte que antigamente os jogos tinham poucos pixels e que eles só podiam ser feitos com pixel art\. 

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545025453800.png)

- Após isso, abra o aplicativo Aseprite:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545026454200.png)

- Vamos criar um arquivo de pixel art:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545028453400.png)

- Vamos definir o tamanho como 16x16:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545032457300.png)

- Vamos iniciar fazendo algo simples\. Explique para os alunos como desenhar, como utilizar a gotinha, o lápis, as cores e as ferramentas do Aseprite\. Inicie fazendo uma carinha com os alunos:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545036454500.png)

- Feito isso, explique para os alunos o que é um frame\. Um frame nada mais é do que um pedaço de uma animação\. Conte para eles que uma animação são vários desenhos passando bem rápido fazendo parecer que o objeto está se movendo\.
- Aproveite o desenho da carinha e faça outro frame\!

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545038501600.png)

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545040510000.png)

- Você irá perceber que tanto o primeiro quanto o segundo frame estão iguais\. Vamos selecionar o segundo frame e mudar o desenho do rosto:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545040510000.png)

- Agora aperte o play e veja a mágica acontecer:

![](https://raw.githubusercontent.com/YanBarbosaLouzada/docx-to-md/master/imagens/img_1767702545042518500.png)

- Caso ache necessário, você pode ensinar aos alunos sobre as camadas, ou sobre mudar o tempo da animação\.
